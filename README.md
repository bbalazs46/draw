# draw
online rajzoló felület, rajzok megosztásához valamint külön érdekesség, hogy támogatja a torzításokat is

## Online mentés

Töltsd fel a `draw5_store.php` fájlt egy PHP-t támogató webszerverre. A `draw5.html` statikus fájlként is működik, letöltve (`file://`) vagy más webszerverről megnyitva is eléri az online mentést/betöltést, és alapból a `https://benderbalazs.hu/draw/draw5_store.php` végpontot használja. A PHP fájl automatikusan létrehozza a `draw5_store_data` mappát a mentésekhez.
